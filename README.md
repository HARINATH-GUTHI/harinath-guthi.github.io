# Harinath Guthi — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Customize before publishing
- Replace the hero placeholder with your professional photo.
- Update the email address in `index.html`.
- Replace LinkedIn/GitHub placeholder links with your actual profiles.
- Add real project screenshots and case-study links.
- Add your final education details and internship/project descriptions.

## Design
Warm editorial palette: espresso brown, cream, sand and muted taupe. Typography uses Playfair Display + DM Sans.
